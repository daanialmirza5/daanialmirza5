### How I build

- **Evidence first.** Rules, statistics and graphs make the decisions people need to trust; language models explain and draft behind a provider interface that can be swapped or switched off.
- **Honest limits.** Synthetic data, simulations and unfinished features are labelled as such in the README and in the product.
- **Tested, then shipped.** Unit, integration and browser tests run in GitHub Actions; deployed demos are opened and checked after each release.
